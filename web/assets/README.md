# Site assets

These files give the themes page the look of the main RiftWii website. They
are copies of files from [RiftWii/riftwii.github.io](https://github.com/RiftWii/riftwii.github.io)
(`site/resources/`), unchanged:

| File | From | License |
| --- | --- | --- |
| `hazebg.png`, `haze1.png`, `haze2.png` | `site/resources/img/` | RiftWii contributors, GPL-3.0-or-later |
| `rounded.ttf` | `site/resources/fonts/` (M PLUS Rounded 1c Bold, cut down to Latin) | SIL Open Font License 1.1 |
| `OFL.txt` | `site/resources/fonts/` | the font's license text, kept next to the font |

`scripts/build_index.py` publishes this folder next to `index.html`.
